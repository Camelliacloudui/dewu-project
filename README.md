# 得物风格电商平台后端

## 项目介绍
这是一个电商平台的后端项目，实现了商品、订单、支付等核心功能。

## 技术栈
- SpringBoot
- MyBatis
- MySQL
- Redis
- Maven
- Git

## 主要功能
- 商品模块：商品列表分页查询、商品详情查询
- 订单模块：下单、订单查询，SQL原子操作防止超卖
- 支付模块：对接支付宝沙箱SDK，处理支付回调

## 如何运行
1. 克隆项目：`git clone https://github.com/Camelliacloudui/dewu-project.git`
2. 导入IDE（IDEA/Eclipse）
3. 配置MySQL和Redis
4. 运行 `Application.java`
